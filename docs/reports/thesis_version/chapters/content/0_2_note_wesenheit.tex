
\begin{notebox}[sharp corners, width=\textwidth]{Wesenheit Function - Equivalence Relation}

For the Wesenheit magnitude, the following relation holds for any color index $(m_1 - m_2)$:
\begin{align}
W_\lambda^{12} = m_\lambda - R_\lambda^{12}(m_1 - m_2) = W_0^{12}.
\end{align}

This equality is violated if the adopted reddening law, extinction, or color excess is incorrect and can only be satisfied when the errors in these parameters are related as follows:
\begin{align}
\delta A_\lambda - R_\lambda^{12}\,\delta E_{12} - \delta R_\lambda^{12}\,E_{12} = 0.
\end{align}

\end{notebox}
